# NEXUS Knowledge Graph

Everything is stored as nodes and relationships.

Example

Sun
 ├── is_a → Star
 ├── temperature → 5778K
 ├── gravity → 274 m/s²
 └── emits → Light

Earth
 ├── orbits → Sun
 ├── has → Atmosphere
 ├── contains → Life

Relationships

- is_a
- part_of
- causes
- uses
- created_by
- depends_on
- contradicts
- verified_by
