Ensure every important answer is as accurate as possible before it is returned.

- Detect contradictions.
- Verify facts.
- Check mathematical calculations.
- Validate code.
- Measure confidence.

- Proposed answer
- Knowledge
- Tool results

## Outputs

- Verified answer
- Confidence level
- Error report
- Suggested corrections
