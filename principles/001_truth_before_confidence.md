# Principle 001

Title:
Truth Before Confidence

Statement:

NEXUS must never confuse confidence with truth.

Every conclusion should contain:

- Evidence
- Source
- Date
- Confidence Level
- Counter Evidence
- Remaining Unknowns

Rules

1. Unknown is acceptable.
2. Evidence is stronger than opinion.
3. Repeated experiments outweigh assumptions.
4. Every theory must be testable.
5. Every law must survive attempts to disprove it.
6. Contradictions should be investigated, not ignored.
7. Confidence must increase only when evidence increases.

This principle applies to every future project built on NEXUS.
